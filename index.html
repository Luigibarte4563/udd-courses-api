API Endpoints

Three endpoints. Everything you need.

Fetch everything at once, or access a single school or program directly by its ID.

GET /data/courses.json

Returns all available schools and their academic programs.

Example GET /data/courses.json Response 200 OK • application/json
GET /data/schools/{id}.json

Returns a single school and its programs. Replace {id} with a school ID (1–8).

Example GET /data/schools/1.json Returns School of Information Technology Education Response 200 OK • application/json
GET /data/courses/{id}.json

Returns a single academic program with its school information. Replace {id} with a course ID (e.g. 101, 204, 501).

Example GET /data/courses/102.json Returns BS Information Technology - Web Development Response 200 OK • application/json
Response Structure

Understand the data.

The API returns one JSON object that groups every academic program under its school. Here is the shape you will receive — both from the full list and from the by-ID endpoints.

response.json JSON 
{
  "schools": [
    {
      "id": 1,
      "name": "School of Information Technology Education",
      "code": "SITE",
      "courses": []
    }
  ]
}
schoolsarray

Contains the list of academic schools.

idnumber

Unique identifier for the school or course.

namestring

Name of the school or academic program.

codestring

Short identifier for the school.

coursesarray

Contains the academic programs belonging to the school.

degreestring

Degree or program type.

majorstring

Major associated with the program, when applicable.

specializationstring

Specialization associated with the program, when applicable.

schoolobject

School details included with each program in the by-ID course response.

How to use the API

Start using the API

  1. 1

    Make a GET request

    Point your browser, terminal, or code at the courses endpoint.

    GET /data/courses.json
  2. 2

    Receive the JSON response

    The server responds with 200 OK and a JSON object containing all schools and programs.

    {
  "schools": [ ... ]
}
  3. 3

    Use the data in your application

    Fetch the data with fetch(), parse the JSON, and use it however you like.

    const response = await fetch(
  "/data/courses.json"
);

const data = await response.json();

console.log(data);
Examples

Code you can copy.

JavaScript examples for fetching, finding, and filtering programs. Replace YOUR_API_URL with the URL where the API is hosted.

Fetch all courses 
const response = await fetch(
  "YOUR_API_URL/data/courses.json"
);

const data = await response.json();

console.log(data.schools);
Finding a course 
const response = await fetch(
  "YOUR_API_URL/data/courses.json"
);

const data = await response.json();

const course = data.schools
  .flatMap(school => school.courses)
  .find(course => course.id === 102);

console.log(course);

This example retrieves course ID 102 from the available programs.

Filtering courses 
const response = await fetch(
  "YOUR_API_URL/data/courses.json"
);

const data = await response.json();

const courses = data.schools
  .flatMap(school => school.courses)
  .filter(course =>
    course.name
      .toLowerCase()
      .includes("computer")
  );

console.log(courses);

Filter the returned data to create custom searches.

Access a course by ID 
// Fetch the course directly by its ID
const response = await fetch(
  "YOUR_API_URL/data/courses/102.json"
);

const course = await response.json();

console.log(course.name);

Access a program directly with its ID. The same pattern works for schools: data/schools/1.json.
